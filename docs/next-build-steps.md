# 到家了么 - 下一阶段开发步骤

> 2026-09-21：早期 React Native 原型规划已经完成或废弃。当前实现与验证结果以 [重构记录](refactoring.md) 和 [iOS 原生模块说明](ios-native-module.md) 为准。

## 当前基线

- 真实位置采点、精度校验、本地地点保存和 iOS 原生围栏同步已经接通。
- 满足地点与权限条件后自动开始守护；主动暂停意图会持久保存。
- “家外长时间无明显移动”已由原生状态机实现，融合可信位置位移、Core Motion 活动和步数。
- 异常直接生成持久的家人通知事件，不提醒本人，也不提供“我没事”按钮。
- 短信快捷指令仅用于前台主动测试，不能视为后台自动送达通道。

## 下一步

1. 在同一 bundle ID 的真机版本上验证运动权限申请和权限撤回后的状态回读。
2. 分别验证锁屏、App 被系统挂起、设备重启和进程被终止后的计时与事件恢复。
3. 在家外进行缩短阈值的受控测试，确认静止只触发一次，移动后可以开启新周期，回家会取消计时。
4. 记录连续定位与 Core Motion 的实际耗电，按真机结果调整采样精度和距离过滤。
5. 选择并接入可在后台自动运行的家人通知通道；在此之前，界面不得暗示短信已经自动发出。

## 验收边界

检测器和通知送达器是两个独立环节。当前阶段可以证明异常在本机被识别、持久保存并进入家人通知队列，但尚不能证明短信、电话或其他外部通知已自动送达。
