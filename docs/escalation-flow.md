# 到家说一声 - 通知升级流程

## 目标

异常时不直接吓到家人，先给本人一个确认机会。如果本人没有响应，再按家人名单顺序升级通知。

## 状态

`getEscalationState` 会根据当前事件流和家人名单生成升级状态：

- `idle`：没有升级中的提醒。
- `self_prompt`：需要先提醒本人。
- `family_queue`：本人未确认，等待通知下一位家人。
- `completed`：家人名单已全部通知。

## 关键事件

- `SAFETY_CHECK_REQUESTED`：系统已提醒本人点击“我没事”。
- `FAMILY_NOTIFIED`：已通知某一位家人。
- `ESCALATION_FINISHED`：名单全部通知完毕。
- `USER_CONFIRMED_SAFE`：本人确认安全，升级流程结束。
- `RETURN_HOME`：回到家，升级流程结束。
- `MOTION_DETECTED`：检测到移动，当前原型视为安全信号。

## 当前演练方式

记录页提供：

- 模拟回家。
- 模拟失联。
- 模拟通知家人。
- 演练下一步升级。

典型流程：

1. 模拟失联。
2. 演练提醒本人。
3. 演练通知第 1 位家人。
4. 演练通知第 2 位家人。
5. 演练完成升级。

后续接入真实通知时，按钮事件会替换为定时器、APNs 推送、短信或电话触达结果。
