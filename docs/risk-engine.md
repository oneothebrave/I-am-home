# 风险状态计算

`guardianProjection.ts` 按完整事件时间排序并按事件 ID 去重，归约得到当前告警、最后可信信号、位置和电量。`riskEngine.ts` 负责将这份结果转换成页面快照。首页、升级流程和通知文案共享该状态。

## 状态规则

- 主动 SOS 立即进入异常，只由 `USER_CONFIRMED_SAFE` 解除。低电量、移动、回家及普通位置更新都不会覆盖 SOS。
- 被动告警转为主动 SOS 时，创建新的告警 ID 和通知队列，旧告警回执不能推进新告警。
- 停留、低电量、位置中断和无运动属于独立风险。可信移动只解除停留和无运动；有效新定位解除位置中断；电量恢复解除低电量。
- 回家可以解除被动告警，但不会解除主动 SOS。
- 家人收到通知或接手处理，不代表本人已经安全。通知完成后仍保留告警。
- 没有可信安全信号或信号已经过期时为 `unknown`，不会默认显示安全。信号有效期使用守护配置的停留阈值。
- 比当前时间超前 30 秒以上的事件不参与当前判断，但保留记录；`now` 可注入以测试时效与跨天。

`LOCATION_UPDATED` 只表示收到有效位置，不能直接当作 `MOTION_DETECTED`。原生层需要先检查测量时间、精度及距离。事件保存 UTC ISO 时间，界面再按本地日期显示。

家外无活动由 Swift 原生状态机在单段守护时段内计时；前台时钟只用于刷新展示。新异常会原子保存风险事件和 Critical Messaging 待发送操作，但不会自动打开系统快捷指令。快捷指令仅保留为用户主动触发的短信测试工具。
