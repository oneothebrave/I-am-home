## P0：Critical Messaging 接入前后必须完成

- [x] 低电量风险执行器（源码已接入，原生验收待完成）
  - 低于阈值时只生成一次风险
  - 连接充电或电量恢复后解除
  - 在定位唤醒和后台刷新机会中重新检查
  - 生成与无活动风险一致的通知操作
- [x] 长时间没有可信位置执行器（源码已接入，原生验收待完成）
  - 区分位置过旧、定位失败、权限关闭、精确位置关闭和后台刷新关闭
  - 获得系统执行机会时立即重新判断
  - 不把手机关机或完全离线描述成仍可持续检测
- [x] Critical Messaging 正式发送状态机
  - 收件人授权、准备、发送中、系统接受、失败和受限状态
  - 每位联系人分别持久化结果
  - 重试次数、间隔、有效期和冷却时间
  - 打开 App 不重复发送，风险恢复后不补发过期告警
  - 区分“系统接受发送”和“家人已经收到”
  - 当前安装包仍关闭 capability 构建开关；获得 entitlement 后再做真实发送验证
- [x] 测试模式与正式模式分离
  - 1 分钟阈值只用于明确的测试模式
  - 测试短信和测试事件显式标注
  - 进入正式模式前检查守护地点、联系人和权限

## 需要产品确认后再开发

- [ ] 家中长时间无活动
  - 手机静止不能证明本人静止，不能直接复用家外规则
  - 需要评估 Apple Watch、可穿戴设备或更保守的多信号规则
- [ ] 多段守护时间
  - 当前版本继续保持单段，避免增加设置复杂度
- [ ] 家人端 App 或服务器通知
  - Critical Messaging 路线可用时暂不建设
  - 只有需要通知历史、家庭协作或跨平台时再评估
